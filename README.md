# expos-ai.github.io

Sends every spelling of the Klemme15 address (for example `expos-ai.github.io/klemme15`) to the real site at
[expos-ai.github.io/Klemme15](https://expos-ai.github.io/Klemme15/). GitHub Pages addresses are case-sensitive, so
without this a lowercase link shows "404 Not Found".

- `404.html` corrects the capitalization and keeps the rest of the address.
- `index.html` sends `expos-ai.github.io` itself to the Klemme15 site.
